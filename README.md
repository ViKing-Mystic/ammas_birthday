# Dearest Amma's Birthday Website 💖✨

A handcrafted, interactive birthday tribute website built with love for **Amma** from **Kuttan (Vishnu) & Ammini (Arya)**.

## 🚀 Features

- 💌 **Interactive Envelope & Cat Intro**: A playful interactive story featuring an envelope delivery and cat animations.
- 📜 **Heartfelt Letter**: Rose gold themed personal birthday letter with embedded photo memories.
- 🖼️ **Memory Wall & Lightbox**: Interactive gallery showcasing cherished family photos with interactive zoom modal.
- 🎂 **Interactive Candle Blowing**: A virtual birthday cake with animated candles to blow out, confetti explosions, and hug button.
- 👑 **Superpowers & Love Jar**: Dynamic interactive cards celebrating Amma's superpowers and love jar quotes.
- 🎵 **Ambient Audio Player**: Built-in background audio player with smooth toggle controls.
- 📱 **Fully Responsive**: Designed mobile-first for phone views, looking gorgeous across all screen sizes.

## 🛠️ Local Development & Running

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn or pnpm

### Quick Start
```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
# Generate production bundle in dist/
npm run build

# Preview production build locally
npm run preview
```

## 🌐 Deployment Options

This project is pre-configured for zero-config one-click deployment on all popular hosting platforms:

### 1. Vercel ⚡ (Recommended)
1. Import your GitHub repository `ammas_birthday` into Vercel.
2. Vercel automatically detects the Vite setup via [`vercel.json`](./vercel.json).
3. Click **Deploy**.

### 2. Netlify 🌐
1. Connect your repository to Netlify.
2. Netlify uses [`netlify.toml`](./netlify.toml) automatically (Build command: `npm run build`, Publish directory: `dist`).
3. Click **Deploy Site**.

### 3. GitHub Pages 🐙
1. Push changes to the `main` branch.
2. The included GitHub Actions workflow at [`.github/workflows/deploy.yml`](./.github/workflows/deploy.yml) will automatically build and publish your site to GitHub Pages.
3. In your repo settings on GitHub, go to **Settings > Pages** and set **Source** to **GitHub Actions**.
